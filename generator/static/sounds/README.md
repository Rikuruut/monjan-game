# 効果音

**今の音は仮の音**(2026年11月1日に Python で合成したもの)。素材が決まったら、同じ名前で置きかえる。
名前や音量は `static/common/sound.js` の `SOUNDS` で決めている。mp3 にするときは、そこのファイル名も変える。

| 名前 | いつ鳴るか | 仮の音 |
|---|---|---|
| `press` | ボタンを押したとき(どのテーマも) | ポンッ |
| `tick` | がったい中に進み具合が1段上がったとき(どのテーマも) | コツッ |
| `crack` | 誕生の瞬間(たまごが割れる・パックが破れる など) | パリーン |
| `fanfare` | カードが出たとき | ジャーン |

素材を選ぶときの注意
- フリー素材サイトの**規約**を確認する(商用・展示で使えるか、クレジットの表記が要るか)
- 会場はさわがしいので、短くて音の立ち上がりがはっきりしたものがよい
- 音量のばらつきは `SOUNDS` の `volume`(0〜1)でそろえる
