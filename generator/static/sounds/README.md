# 効果音

**今の音は仮の音**(2026年11月1日に Python で合成したもの)。素材が決まったら、同じ名前で置きかえる。
名前や音量は `static/common/sound.js` の `SOUNDS` で決めている。mp3 にするときは、そこのファイル名も変える。

| 名前 | いつ鳴るか | 仮の音 |
|---|---|---|
| `press` | ボタンを押したとき(どのテーマも) | ポンッ |
| `tick` | がったい中に進み具合が1段上がったとき(どのテーマも) | コツッ |
| `crack` | 誕生の瞬間(たまごが割れる・パックが破れる など) | パリーン |
| `fanfare` | カードが出たとき | ジャーン |

BGM:`bgm.mp3`(「光差し込む森」。OpenTracks(旧 DOVA-SYNDROME)のフリー BGM。2026年11月2日に依頼者が選んだ)。撮影・合体のページを開いたらくり返し流す。音量は `sound.js` の `BGM`

がったい中の BGM:`fusion1.mp3`・`fusion2.mp3`・`fusion3.mp3`(2026年11月2日に依頼者が足した。元のファイル名の #1・#2・#4 の順)。がったい中(場面 s3。誕生の演出まで)だけくり返し流し、そのあいだ `bgm.mp3` は小さくする(`sound.js` の `BGM_DUCK_VOLUME`)。どれを流すかは開発者メニューの「がったい中の BGM」で選ぶ(1〜3・なし。ブラウザの localStorage `monjan-fusion-bgm` に残る。既定は 1)。音量は `FUSION_BGM_VOLUME`

素材を選ぶときの注意
- フリー素材サイトの**規約**を確認する(商用・展示で使えるか、クレジットの表記が要るか)
- 会場はさわがしいので、短くて音の立ち上がりがはっきりしたものがよい
- 音量のばらつきは `SOUNDS` の `volume`(0〜1)でそろえる
