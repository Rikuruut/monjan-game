# Codex開発ルール（モンじゃん！）

- 作業前に `docs/GAME_SPEC.md`、`docs/SCREEN_SPEC.md`、`docs/TEST_CASES.md`、`docs/DATA_SPEC.md` を読むこと。
- 未確定事項を勝手に正式決定しない。実装に必要な仮定は `README.md` の「暫定実装上の仮定」に明記する。
- 最初の目標は **React + TypeScript + Vite によるPC用16:9ブラウザゲーム（オフライン寄り）**。
- 初回はサンプルJSONとPNGのみ利用。画像生成API、プリント、写真送信、オンラインマルチプレイは実装対象外。
- じゃんけんロジックはUIから分離してpure functionにし、Vitestでテストする。
- ステータスはJSONの `attack`, `hp` を1000単位の数値で保持し、UIでは `attack/1000`個の⚔、`hp/1000`個の♡を描画する。
- ★（レア度）の制度は2026年11月4日にやめた。同じ手は連打勝負（docs/GAME_SPEC.md）。CPUの手はプレイヤーの選択後まで隠す。
- 攻撃ダメージは勝ったモンスターの⚔個数（相手の♡が1のときにじゃんけんで勝つと必殺技の演出でとどめ。ダメージは同じ⚔個数。2026年11月9日に×2をやめた）。連打も同じ回数の場合の双方ダメージはそれぞれ♡1個（ATK非依存）。
- ダメージ後のHPは0未満にしない。同時0なら専用引き分け画面へ。
- 終了後にタイトルへ戻るとゲーム状態を初期化し、次のプレイで正常に動くこと。
- レイアウトは1920x1080を基準とした16:9だが、ブラウザサイズに応じて破綻なくスケールすること。
- 長い日本語説明を避け、小学生に分かる用語・大きな操作ボタン・読みやすいコントラストを用いる。
- 画像素材・JSONは変更せず、必要なら別ファイルとして追加すること。
- 最後にインストール方法、起動コマンド、テスト結果、実装したこと、残タスクを報告すること。
