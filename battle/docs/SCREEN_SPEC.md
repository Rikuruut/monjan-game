# モンじゃん！ 画面・遷移仕様

## 画面遷移（PC横16:9、1920×1080基準）
タイトル → スタート → バトル画面（最初に説明ポップアップ表示） → バトル本編 → 勝利/敗北/引き分け結果画面 →「あそんでくれてありがとう！」 → タイトル

- 最初のルール説明は、本物のバトル画面での「練習ラウンド」(2026年11月4日から。下の S02)。「📖 ルール」での見直しだけ、ゲーム内ポップアップ(3ページ)で表示し、閉じたら選択できる。
- 引き分け時は専用画面「引き分け！最後は本物のじゃんけん！！」で現実じゃんけんを案内。終了画面へ手動で進む。
- タイトルに戻る際はラウンド、HP、手、星、画面演出状態をリセット。

## 各画面
### S01 タイトル
- ゲーム名「モンじゃん！」、スタートボタン。
### S02 練習ラウンド(最初のルール説明)
- スタートのあと、本物のバトル画面で1ラウンドだけ練習する。上に「れんしゅう」のチップを出す。
- 手をえらぶ前の吹き出し:「グー・チョキ・パーから1つえらぼう！」「◀ ● ▶ のボタンでもえらべるよ」「★は つよさ。同じ手のときは★が多い方のかち！」(手のボタンと★を光らせる。えらぶまで待つ)
- 練習は必ず勝つ(どの手でも相手が負ける手を出す)。CPU の♡は自分の⚔より多くして、♡が0にならない。「📖 ルール」は押せない。
- 結果で止まり、吹き出し「⚔の数だけ相手の♡がへるよ」「♡をぜんぶなくしたらかち」。中ボタン「バトルスタート！」で♡を本来の数にもどし、星の抽選から本番ラウンド1へ。
- ### S02b 見直しポップアップ(「📖 ルール」)
  - 背景はバトル画面。3ページ(じゃんけん・★・⚔と♡)。表示文例「グー・チョキ・パーをえらぼう！」「あいこなら★が多い方の勝ち！」「★も同じなら、おたがいの♡が1つへるよ！」
### S03 バトル
- 上段左：プレイヤーモンスター。上部にATK⚔、下部に残りHP♡。
- 上段右：CPUモンスター。上部にATK⚔、下部に残りHP♡。
- 両者の中央：VS。
- 下段：横並びの「✊ グー」「✌️ チョキ」「✋ パー」3ボタン。各ボタン右上に当ラウンドの★表示。
- 選択後はCPUの手と星を公開し、勝敗・減った♡をフィードバック。
- 機械的に画像を動かす簡単なアニメーションは可能。AIで攻撃動画は生成しない。
### S04 勝利結果 / S05 敗北結果
- それぞれ結果を大きく表示し、終了画面へ移動。
### S06 引き分け結果
- 「引き分け！最後は本物のじゃんけん！！」の専用画面。
- 現実のじゃんけんが終わったらスタッフがボタン操作して終了画面へ。
### S07 終了
- 「あそんでくれてありがとう！」を表示。タイトルへ戻るボタン。
