# モンじゃん！ ゲーム基本仕様 v0.1

## 1. 目的と範囲
- 子ども・家族向けイベントで、AIにより生成された自分だけのモンスターを使ってCPUとじゃんけん対戦する。
- 来場者一人につき全体の体験時間目標は3〜4分。
- 初回のCodex実装ではゲーム本体のみ作成し、AI画像生成・写真アップロード・カード印刷との自動連携は次段階。

## 2. モンスター
- プレイヤー側：将来は生き物名＋持ち物写真から生成。本試作ではサンプル画像・JSONを読み込む。
- CPU側：あらかじめ登録した画像・JSONを読み込む。
- 名前、属性、説明文、画像、ATK、HPを持つ。
- ATKは⚔1〜3個、数値1000/2000/3000。
- HPは♡1〜5個、数値1000〜5000（1000刻み）。
- 属性はカードや見た目に使うが、じゃんけんの勝敗やダメージを変えない。
- 説明文は小学3年生程度で読みやすい言葉、ふりがななし。

## 3. 各ラウンドの流れ
1. プレイヤー側の各手（rock/scissors/paper）に★1/★2/★3を重複なしでシャッフルして割り当て、ボタンに表示する。
2. CPU側も独立に同様の割り当てを行う。CPU側の手と星はこの時点ではプレイヤーに見せない。
3. プレイヤーがボタンを押す。CPUはランダムに手を決める。入力をロックして結果を確定する。
4. 通常のじゃんけんで勝敗を判定。勝敗がつくとき星の数は無関係。
5. 手が同じ場合、星が多い方の勝ち。同じ星なら勝者なし・双方に♡1ダメージ。
6. 勝者は自分の⚔個数（ATK数値÷1000）分だけ敗者の♡を減らす。
7. 新しいHPを表示。どちらかが0なら結果画面へ。両方0なら引き分け画面へ。両方残っていれば次ラウンドを開始し星を再割当。

## 4. じゃんけん判定
- グーがチョキに勝つ、チョキがパーに勝つ、パーがグーに勝つ。
- 違う手なら星の大小で逆転しない。
- 同じ手で星も同じなら双方のHPを必ず1減らす（ATK非依存）。

## 5. 終了条件
- プレイヤーの♡>0、CPUの♡=0 → 勝利画面。
- プレイヤーの♡=0、CPUの♡>0 → 敗北画面。
- 両者の♡=0 → 引き分け専用画面。「最後は本物のじゃんけん！」と表示し、その場で来場者とスタッフがじゃんけん。最後は「遊んでくれてありがとう」画面へ進む。
- HPが負になる場合は0で止める。

## 6. ラウンドと速度
- ラウンド上限やタイムアウト勝敗ルールは未決定。勝手に追加しない。
- 連打で二重判定しないこと。結果の演出後に次ラウンドへ進む。
- 最終的な速度は実際の会場運用でテストする。

## 7. 確定事項 / 暫定事項
確定：じゃんけん優先、各手の★1〜3の毎ラウンド再割当、通常勝ちのATKダメージ、同じ手同じ星で双方1減、同時ゼロ時は現実じゃんけん、PC横16:9。
暫定：サンプルモンスターの名前・属性・強さ、効果音とアニメーション、最初に表示する相手。
未決定：API事業者・自動生成の運用、印刷機種・サイズ、ラウンド時間制限の有無、ステージ背景詳細。
