# 最低限のテストケース

1. `rock`対`scissors`でrock勝ち（星1対星3でもrock勝ち）。
2. `scissors`対`paper`でscissors勝ち。
3. `paper`対`rock`でpaper勝ち。
4. `rock`対`rock`でプレイヤー星3、CPU星1ならプレイヤー勝ち。
5. `paper`対`paper`でプレイヤー星1、CPU星3ならCPU勝ち。
6. 同じ手・同じ星なら双方のHPをそれぞれ1ハート減らす。ATKによらない。
7. プレイヤーATK3000で勝った場合、CPUのHPを3ハート減らす。
8. CPU ATK2000で勝った場合、プレイヤーのHPを2ハート減らす。
9. HPは0未満にならない（残り1に3ダメージでも0）。
10. 同じ手・同じ星で、残りHP1対1から双方0になったら引き分け専用画面へ。
11. CPUのみHP0なら勝利画面、プレイヤーのみHP0なら敗北画面。
12. 各ラウンドのプレイヤー星とCPU星がそれぞれ[1,2,3]の順列になっており、重複しない。
13. 次ラウンド開始時に再抽選する（乱数を注入して複数パターンを検証）。
14. CPU手はプレイヤーの選択から独立してランダムに決まる。
15. 選択前にCPUの手・星が見えず、選択後に公開される。
16. 結果判定中にボタン連打してもHPが複数回減らない。
17. タイトルへ戻ったあと新しいゲームを始めるとHPと星状態が初期化される。
18. JSONの画像パスが正しく解決される。欠損/壊れたJSONではエラーが表示される。
19. 1920×1080、1366×768、おおむね16:9のウィンドウで文字/ボタンが欠けない。
20. 見直しのポップアップを閉じた後だけグー・チョキ・パーが押せる。
21. 最初のスタートは練習ラウンド(「れんしゅう スタート！」):吹き出し→どの手でも勝つ→結果で止まる→「つぎへ」で「れんしゅうクリア」画面→「ほんばん スタート！」で本番を召喚から(♡満タン・ラウンド1)。CPU の♡が1でも練習で勝負が終わらない。見直し(📖)では練習は出ず、練習中は📖が押せない。
22. 練習の相手は、本番の CPU・自分のモンスター以外の見本(足りないときだけ本番の CPU と同じ)。本番の相手は本番の召喚ではじめて出る。
