# プロジェクター実機確認チェックリスト

Web画面側では高輝度環境を想定し、重要な文字を濃紺、操作カードを高不透明度、空のハートを濃いグレーへ調整しています。
最終確認は使用する会場・機材で次の条件を確認してください。

## 推奨確認環境
- PC出力：1920×1080、ブラウザ拡大率100%、全画面表示
- 会場照明：イベント本番と同じ明るさ
- 視認距離：画面から約3m
- プロジェクター：通常モードと高輝度モードの両方

## 確認項目
- [ ] タイトルのゲーム名とスタートボタンが離れた場所から読める
- [ ] バトル上部のロゴ、モンスター名、ATK、HPが背景に埋もれない
- [ ] 満タンのハートと空のハートを見分けられる
- [ ] あいこの連打勝負で、あなた と CPU のゲージを見分けられる
- [ ] 「あなたのかち」「CPUのかち」と次ラウンド案内が読める
- [ ] サウンドON/OFFの状態をスタッフが確認できる
- [ ] 音量が会場アナウンスを邪魔せず、被弾音と勝利音を聞き分けられる

## 調整の目安
- 白飛びする場合：プロジェクターの明るさを下げるか、映像モードを「標準」にする
- 暗い場合：PC側の明るさではなく、プロジェクター側の輝度を調整する
- 音が大きい場合：PCのシステム音量を先に調整し、ゲーム画面のサウンドボタンは一時消音に使う
