# 次段階の機能（初回Codex実装対象外）

1. スタッフが子どもの好きな生き物を聞く。
2. スマホで物を撮影、またはライブラリ画像を選び、専用WebページからPC側へ送る。
3. 画像生成API（サービス未確定）で「生き物＋物」のモンスターを生成する。ChatGPT Plusでの手動生成も候補だが、専用システムへの自動組み込みには通常API等が必要。
4. 別途名前・属性・説明・ATK・HPを決定し、Monster JSONとPNGに保存する。
5. Python/Pillowで固定カードテンプレートに画像・文字・アイコンを合成する。
6. カード印刷をゲームと並行で実行し、バトル終了時に来場者へ渡す。

カードの確定イメージ：縦型、パステルカラー×透明感のある水彩風。左上に属性、上部に名前、中央に大きなモンスター画像、下に小3が読める説明文（ふりがななし）、最下段にATK枠とHP枠が左右別々。属性はバトルへ影響しない。

運用上の留意：アップロード写真に人物や個人情報が入らないよう案内、入力ファイルのサイズ/形式検証、写真と生成結果の保管期間、複数来場者のデータ混同防止のセッションID、印刷失敗時の再送機能、画像生成待ち時間の実測。
