# 次段階：モンスター画像生成プロンプト（コピー用）

添付された物の写真と指定された生き物を自然に融合させたオリジナルモンスターを描いてください。
生き物：{animal}
物：{object}
参考画像：添付写真

生き物と物の両方の特徴が一目で分かるようにし、物を単に持たせず、その色・形・素材・機能をモンスターの体の一部として取り入れてください。かわいさ70％、かっこよさ30％。表情豊かな大きな目、親しみやすい表情、丸みのあるシルエットを基本としながら、それぞれの生き物の特徴やモンスターらしい強さを残してください。

画風は「透明感のある水彩ゲームイラスト風」。柔らかい水彩のにじみ、明るく澄んだ色彩、淡いグラデーション、ふんわりした筆致、パステルカラー、きらめく光、華やかなファンタジーの雰囲気。2Dデジタルゲームイラストとして視認性が高く、全体像が分かる躍動感のあるポーズで大きく描いてください。背景は明るい幻想的な風景で主役を邪魔しない。怖すぎる表情や過度に攻撃的な表現は避けてください。画像に文字・名前・ロゴ・数値・カード枠は入れないでください。カードの中央イラストに使える高品質な仕上がりにしてください。

※ 名前・説明文・属性・HP・ATKは別JSONで管理し、カードレイアウトへの書き込みは後段のPillowで行う。
