# モンじゃん! プロトタイプ

「写真 + 動物」から、OpenAI APIでモンスター情報と画像を作れるかを確かめるためのプロトタイプです。
仕様は [CLAUDE.md](CLAUDE.md) を参照してください。

---

## 1. 準備

### 必要なもの
- Python 3.11以上
- ノートPCとスマホ(**同じWi-Fiにつなぐ**)
- OpenAI APIキー(段階4以降で必要)

### インストール

```powershell
# 仮想環境を作る
py -m venv .venv
.\.venv\Scripts\Activate.ps1

# ライブラリを入れる
pip install -r requirements.txt
```

> **メモ**:このPCでは `python` と打つとMicrosoft Storeのダミー(WindowsApps)が動いてしまい、
> 仮想環境が作れません。`py` を使ってください。
> `py` も使えない場合は、Pythonの実体を直接指定します。
> `C:\Users\<ユーザー名>\AppData\Local\Python\pythoncore-3.14-64\python.exe -m venv .venv`

### 設定ファイルを作る

`.env.example` をコピーして `.env` を作り、値を書き込みます。

```powershell
Copy-Item .env.example .env
```

| 項目 | 内容 |
|---|---|
| `OPENAI_API_KEY` | OpenAIのAPIキー |
| `TEXT_MODEL` | 物の判定に使うモデル(画像入力に対応したもの) |
| `IMAGE_MODEL` | モンスター画像の生成に使うモデル |
| `IMAGE_QUALITY` | 画質(`low` / `medium` / `high`) |
| `IMAGE_SIZE` | 画像サイズ(既定 `1024x768` = 4:3。幅・高さとも16の倍数) |
| `API_TIMEOUT_SECONDS` | 判定のタイムアウト秒数(既定 60) |
| `IMAGE_TIMEOUT_SECONDS` | 画像生成のタイムアウト秒数(既定 120) |
| `ALLOW_PERSON` | 人が写った写真も生成するか(既定 `false`)。詳細は下の「人が写った写真について」 |
| `FUSION_TYPE` | 融合の型。空なら毎回ランダム。`weapon`(武器)/ `body`(体の部位)/ `armor`(よろい)で固定 |
| `IMAGE_PROMPT_STYLE` | 画像プロンプトの書き方。`detailed`(設計図つき)/ `simple`(Playground と同じ短いもの)。既定 `detailed` |
| `FUSION_PART` | 短いプロンプトで、物を取り込む場所。空なら動物ごとにランダム。`jaw` / `tail` / `back` / `head` / `arm` / `armor` / `silhouette` で固定 |
| `PC_THEME` | PC画面(大画面)の見た目。`lab`(ひみつけんきゅうじょ)/ `fantasy`(モンスターのたまご)/ `cardpack`(カードパック かいふう)/ `pot`(まほうの おなべ)/ `gacha`(ガチャガチャ)/ `summon`(しょうかんの まほうじん)。既定 `lab` |
| `KIOSK_MODE` | 起動したときに、PC用ページをキオスクモード(全画面)で開くか(既定 `true`)。詳細は「2. 起動」 |
| `KIOSK_BROWSER` | キオスクモードで使うブラウザの場所。空なら Edge → Chrome の順に探す |
| `PORT` | サーバーのポート番号(既定 8000) |

動作を確認した組み合わせ:

```
TEXT_MODEL=gpt-6-luna
IMAGE_MODEL=gpt-image-2
IMAGE_QUALITY=medium
```

`IMAGE_MODEL` を `gpt-image-1-mini` に変えると、別のモデルでも試せます。

> **画像生成は30秒では間に合いません。**
> 実測で約35秒かかるため、画像生成だけ `IMAGE_TIMEOUT_SECONDS`(既定120秒)を使っています。

`.env` は**Gitに含めません**。APIキーをコードに直接書かないでください。

## 2. 起動

```powershell
.\.venv\Scripts\Activate.ps1
python -m app.main
```

(仮想環境を有効にしていれば、この `python` は `.venv` の中のPythonです)

起動すると、ターミナルに次のように表示されます。

```
========================================================
  モンじゃん! プロトタイプ サーバーを起動しました
========================================================
  PC用ページ   : http://localhost:8000/
  スマホ用ページ: http://192.168.x.x:8000/phone
========================================================
```

- **PC**:起動すると、PC用ページが**キオスクモード**(全画面・アドレスバーなし)で自動的に開く
- **スマホ**:表示されたURL(または画面のQRコード)を開く

### キオスクモード

- Edge(なければ Chrome)を `--kiosk` 付きで立ち上げる(`app/kiosk.py`)。ページの側からはキオスクモードにできないため
- **終わるときは Alt + F4**。開発者メニューは、キオスクモードでも D キーで開ける
- ふだん使っている Edge が開いていても全画面になるよう、キオスク専用のプロフィール(`%LOCALAPPDATA%\monjan-kiosk`)で起動する
- テーマは `.env` の `PC_THEME` のもの(途中で変えるときは開発者メニューから)
- サーバーを起動し直すと、もう1つ窓が開く。先に Alt + F4 で閉じておく
- 自分でブラウザを開きたいときは、`.env` を `KIOSK_MODE=false` にして `http://localhost:8000/` を開く

## 3. 使い方

**動物を選ぶのはスマホ側です。**PCでは選びません。

1. PCの画面で「スマホ:接続中」になっているか確認する
2. PCで「スマホでとる」を押す
3. スマホに**動物のプルダウン(5種類)**と大きな「とる!」ボタンが出る
4. スマホで動物をえらび、「とる!」をタップしてカメラで撮影する
5. 写真と動物の名前がPCの画面に表示される
6. PCで「生成する」を押す → 判定結果とモンスター画像が表示される

動物は10種類(ライオン / ゾウ / ウサギ / ペンギン / ネコ / 鷹 / ワニ / ゴリラ / サメ / ティラノサウルス)です。
製品版ではユーザーが自由に入力できるようにする予定のため、
サーバー側は一覧に無い動物名でも受け付けるように作ってあります。

---

### PC画面の見た目(テーマ)の切りかえ

PC画面(展示の大画面)の見た目は、テーマごとに分けてあります。

- `http://localhost:8000/?theme=lab` … ひみつけんきゅうじょ(がったいマシン)
- `http://localhost:8000/?theme=fantasy` … モンスターのたまご
- `http://localhost:8000/?theme=cardpack` … カードパック かいふう
- `http://localhost:8000/?theme=pot` … まほうの おなべ
- `http://localhost:8000/?theme=gacha` … ガチャガチャ
- `http://localhost:8000/?theme=summon` … しょうかんの まほうじん
- 何も付けないときは `.env` の `PC_THEME` のテーマ
- 開発者メニュー(右下のボタンか D キー)の「テーマ」からも切りかえられる

新しいテーマを作るときは、`static/themes/<テーマ名>/` に `index.html` と `style.css`(と表示名を書いた `theme.json`)を置くだけで選べるようになります。
動き(撮影・生成・場面の進行)は `static/common/app.js` が共通で受け持つので、テーマ側は見た目だけを作ります。
`index.html` に用意する要素は、`app.js` の先頭の「テーマとの約束」に書いてあります。

### 名前のテスト

PC画面のいちばん下の「7. 名前のテスト」で、動物と物の名前だけから、モンスター名を何回か作れます。
写真も画像生成も使わないので、料金は1回 0.1円以下です。名前のプロンプト(`app/prompts.py` の `NAME_RULES`)を調整するときに使います。
結果は `outputs/name_tests.jsonl` に残ります。

## 4. 注意点

### Windowsのファイアウォール
初回起動時に「Windowsセキュリティの警告」が出ます。
**プライベートネットワーク**にチェックを入れて「アクセスを許可する」を押してください。
許可しないと、スマホからPCにつながりません。

### 同じWi-Fiにつなぐ
PCとスマホは**同じWi-Fi**につないでください。

公共のWi-Fiやゲスト用Wi-Fiは、**端末同士の通信が禁止されている**ことが多く、
同じWi-Fiに見えてもつながりません。その場合は次を試してください。

- スマホのテザリングを使い、PCをそこにつなぐ
- 自宅や社内のWi-Fiを使う

### 人が写った写真について

既定(`ALLOW_PERSON=false`)では、人が写っている写真は**撮り直し**になります。

`.env` で `ALLOW_PERSON=true` にすると、人が写っていても撮り直しにせず、
顔立ち・髪型・服の色などを取り込んだモンスターを作ります(面白枠)。

ただし、次の点に注意してください。

- **撮られる本人(と保護者)の同意が取れている場合だけ** true にしてください
- 通りすがりの他人が写り込むおそれがあるため、**展示本番は `false` に戻す**のが安全です
- OpenAIの画像モデルは実在の人物の扱いに制限があり、
  **コンテンツフィルターで拒否されることがあります**。その場合はエラーがそのまま表示されます
  (同じ写真でリトライはしません)

### カメラについて
- カメラは `<input type="file" capture="environment">` で開きます
- ブラウザの制約で、カメラを開くには**スマホ上でのタップが必要**です
  (PCのボタンだけで撮影まで終わらせることはできません)
- 写真はスマホ側で長辺1024pxのJPEGに変換してから送ります
  (容量を減らすため / iPhoneのHEIC形式への対策)

## 5. 保存先

生成結果は `outputs/YYYYMMDD_HHMMSS/` に保存されます。

| ファイル | 内容 |
|---|---|
| `photo.jpg` | 元の写真(縮小後) |
| `monster.png` | 生成されたモンスター画像 |
| `result.json` | 判定結果、モデル名、画質、処理時間、動物の名前 |

スマホから届いた写真は、いったん `uploads/` に置かれます。
`outputs/` と `uploads/` はGitに含めません。

## 7. 実測の処理時間

テスト用の画像(はさみの絵 × ライオン)で計測した値です。

| 処理 | 時間 |
|---|---|
| 判定(gpt-6-luna) | 約 4〜7 秒 |
| 画像生成(gpt-image-2 / medium) | 約 35 秒 |
| **合計** | **約 41 秒** |

撮影から画像ができるまでは、**おおよそ40〜50秒**とみておけば良さそうです。

## 8. APIの料金

**1回の生成(判定 + 画像1枚)で、$0.0498(約7.5円)です。**
以下は推測ではなく、2026年10月28日の**実測値**です(`gpt-image-2` / medium / 1024×768)。

| 処理 | トークン | 料金 |
|---|---|---|
| 判定(`gpt-6-luna`) | 入力1,917 / 出力303 | $0.0003(約0.1円) |
| 画像生成(`gpt-image-2`) | 入力2,206 / 出力1,204 | $0.0495(約7.4円) |
| **合計** | | **$0.0498(約7.5円)** |

ほぼ全額が画像生成です。判定はほとんどかかりません。

### 画像サイズによる違い

料金は画素数にほぼ比例します。**プロンプトの長さはほとんど影響しません**
(日本語の詳細プロンプト1,438トークンぶんでも約1.1円)。

| サイズ | 1枚あたり | 300dpi印刷時 |
|---|---|---|
| **1024×768(4:3・既定)** | 約 **7.5円** | 87×65mm |
| 1280×960(4:3) | 約 10.5円 | 108×81mm |
| 1536×1152(4:3) | 約 14.2円 | 130×98mm |
| 1024×1024(正方形) | 約 9.3円 | 87×87mm |
| 1024×1536(縦長) | 約 12.9円 | 87×130mm |

### 画質による違い(1024×768)

| 画質 | 1枚あたり |
|---|---|
| `low` | 約 3.4円 |
| **`medium`(既定)** | 約 7.5円 |
| `high` | 約 23.7円 |

### モデルによる違い(1024×768 / medium)

| モデル | 1枚あたり |
|---|---|
| **`gpt-image-2`(既定)** | 約 7.5円 |
| `gpt-image-1-mini` | 約 2.2円 |

### 使用量の確認方法

生成するたびに、実際のトークン数と料金の試算が記録されます。

- **PC画面**:「APIの使用量と料金(試算)」の欄
- **保存先**:`outputs/.../result.json` の `usage`

単価は `app/pricing.py` に定義しています
(2026年10月28日時点の公式料金。**変わることがあるので使う前に確認してください**)。

### 料金を抑えるには

**いちばん確実なのは「からうちモード」です。**

`.env` の `DRY_RUN=true` にすると、**OpenAI APIを一切呼ばず**に、決まった判定結果と
ダミー画像を返します。**料金は0円**です。

```
DRY_RUN=true
```

画面の確認、スマホの接続確認、WebSocketの動作確認など、**絵の中身が関係ない作業**は
すべてこのモードで行えます。絵を実際に見たいときだけ `false` に戻してください。

ダミー画像には「DRY RUN(からうちモード)」と描かれているので、
本物と取り違えることはありません。

そのほか:

- **撮り直しの判定で止まった場合、画像生成は呼ばれません**(判定の約0.1円だけで済みます)
- 調整中は `IMAGE_QUALITY=low` にすると約1/2になります
- モデルを `gpt-image-1-mini` に変えると約1/3になります
